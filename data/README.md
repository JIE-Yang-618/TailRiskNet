# Data

- `demo/` contains fully synthetic weekly returns, states, institution metadata, and the known directed graph generated by `tailrisknet.simulation`.
- `raw/` is reserved for licensed or private empirical inputs and is ignored by Git.

The synthetic identifiers (`B1`, `S1`, `I1`, and so on) do not refer to real institutions. Curated demo results therefore illustrate the workflow without making empirical claims about China or any firm.

See [`docs/DATA_SCHEMA.md`](../docs/DATA_SCHEMA.md) for the complete input contract.
